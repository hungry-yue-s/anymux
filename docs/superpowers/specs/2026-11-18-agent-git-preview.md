# Agent 打开提交预览

让 agent 完成提交后，运行 `anymux git show <提交号> [--repo <仓库>]`，把那笔提交的说明、文件列表和改动直接打开在所属 tmux 窗口的 Git 标签里。

- 服务端核对预览目录、仓库及提交，解析为固定的完整提交号；只查看，不改变仓库。
- 按事件来源服务器、tmux 实例和窗格定位窗口。不在目标窗口时后台保存，回来可直接查看；不抢键盘焦点，不关闭 modal，不展开用户收起的侧栏。
- 复用现有 Git 提交渲染和大提交加载限制；目标提交不受默认历史条数或当前分支限制。同一窗口同一仓库复用标签，保留提交草稿。
- 自动打开的提醒放在左侧所属窗口，点击“查看”才切窗打开；收起会话时放在所属会话下。强调最多 2.4 秒，访问窗口就停止；实际显示对应提交后确认已读，加载失败不清掉提醒。新标签显示“新”标记，通知可回看；再次打开前重新核对窗口，旧实例不误投新窗口。
- 文档说明供 agent 调用的命令；本项目任务完成提交后执行一次。其它 agent 也能主动调用，不为所有 Git 提交安装 hook。
