## Anymux 文档分窗

在 Anymux 面板的 tmux 窗格里工作时（环境变量 `TMUX` 存在、下面的命令可用），要给用户看的长内容写成文档，在面板右侧分窗里打开，不要整段输出在对话里。Anymux 命令：`{{anymux}}`。

- 什么时候写：预计超过一屏（约 40 行），或者是方案、设计、调研、评审结论、计划清单、对比、Mermaid 图这类要边看边讨论的内容。简短回答、单条命令、代码改动本身留在对话里；用户说"直接说""不要文档"时也留在对话里。
- 写在哪：依次看用户这次指定的路径、项目 AGENTS.md / CLAUDE.md 的文档放置约定、正在使用的 skill 规定的位置（例如 superpowers 的 `docs/superpowers/…`，照它的流程走）。都没有就执行 `{{anymux}} doc path <主题>`，它打印草稿路径（项目内 `.anymux/docs/`，不进 git）。
- 用自己的写文件工具写入，再执行 `{{anymux}} open --dock <路径>`。命令失败就忽略，照常回答。
- 对话里只写一行路径和三到五行要点。同一主题继续改同一个文件，侧栏自动刷新；用户在文件里改过或勾过的内容先读再改。
- 草稿放进项目、提交或推送之前，按 agent-docs skill 的规则决定位置以及要不要先问用户。
